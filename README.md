# Responsibility Constructions

Resources accompanying the paper:

"Who is Responsible? Constructional Patterns of Agency in Italian Political Debate about Environment"

## Interactive Constructicon

https://elliechierchi.github.io/responsibility-constructions/

## Repository contents

- `responsibility_queries/`: Grew queries for responsibility constructions
- `impersonality_queries/`: Grew queries for impersonal and necessity constructions
- `grew_run.ipynb`: example notebook for query execution and result extraction

## Requirements

- Grew
- Python 3
- Universal Dependencies formatted corpora
